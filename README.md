# 🏮 Lunar Mindful Notes & Quantitative Fortune Dashboard (黄历吉凶与心境专注工作台)

> 传统黄历智慧与现代心流效率的深度融合，集吉凶量化动力学预测、习惯复利连击追踪、深度反省卡片复盘、7天数据安全监护与 GitHub 仓库全量同步于一体的现代化应用。

---

## ✨ 核心特性

### 1. 📅 传统黄历与每日心流灵感
- **精确干支历算**：农历、天干地支、生肖、廿四节气、彭祖百忌、吉神凶煞全维展示。
- **宜忌与吉时**：精细化宜忌解读与吉时排布。
- **每日 AI 智见**：结合当日气场生成哲理引言与灵感卡片。

### 2. ⚡ 量化吉凶动力学预测系统 (Quantitative Fortune Dynamics)
- **气象环境函数加权**：
  - ☀️ **晴朗**：阳和舒畅，正向吉势函数加权 **1.2 倍**
  - ⛅ **多云**：拨云见日，正向吉势函数强加权 **1.6 倍**
  - 🌧️ **雨天**：雨落阴湿，凶相耗损阻力加权 **1.6 倍**
  - ⛈️ **暴雨**：风雨交加，凶势阻力翻倍 **2.0 倍**
- **连击与习惯动力学法则**：
  - **坚持正向活动复利递增**：分值随坚持天数复合放大（坚持越久加分越多）。
  - **中断破戒重挫严惩**：惯性坍塌与沉没成本反噬，按坚持天数成倍重扣。
- **蝴蝶效应与吉凶守恒天平**：非线性波动推演，智能平抑极吉极凶波形。

### 3. 📝 深度反省与卡片复盘管理
- **卡片看板**：支持拖拽排序、状态流转（进行中/已完成/沉思中）。
- **Markdown 智能富文本渲染**：清晰记录个人反思、目标计划与复盘日志。
- **自身反省与提醒文件夹导入**：支持批量导入卡片并自动生成小旁白。

### 4. 🛡️ 7 天数据安全监护与 GitHub 仓库全量同步
- **状态感知定时器**：实时跟踪上次备份时间，超过 7 天自动激活呼吸灯预警。
- **全量代码与数据一键推送到 GitHub 仓库**：
  - 支持直接将整套工程源代码与用户卡片数据全量推送到用户指定的 GitHub Repository；
  - 支持仓库一键新建、分支指定、自动获取 SHA 增量更新。

## 🛠️ 技术栈

- **前端**：React 19, TypeScript, Tailwind CSS, Vite, Lucide Icons, Framer Motion, Recharts
- **后端服务**：Express, tsx, Node.js
- **历算算法**：Lunar-javascript
- **大模型 SDK**：@google/genai (Gemini 3.5 Flash)

---

## 🚀 本地快速启动

```bash
# 1. 安装依赖
npm install

# 2. 启动开发服务器 (默认端口 3000)
npm run dev

# 3. 生产环境构建
npm run build

# 4. 运行生产服务
npm start
```
